# EverLearn 🎓

A responsive online learning platform where users can explore courses, browse categories, and discover expert instructors. Built with HTML, CSS, and JavaScript.

## 🌐 Live Demo

[View EverLearn Website](https://muhaned-7.github.io/EverLearn/)

## 📌 About the Project

EverLearn is a front-end web development project created to practice and improve web development skills. It features a clean, modern design with a blue color scheme and a responsive layout for desktop, tablet, and mobile devices.

## ✨ Features

- **Responsive Navigation:** Navigation links and a toggleable mobile menu.
- **Search Interface:** Toggleable course search input.
- **Hero Section:** Introduction, call-to-action buttons, and learning statistics.
- **Featured Courses:** Course details, instructors, ratings, durations, and prices.
- **Course Categories:** Browse different learning categories.
- **Top Instructors:** Instructor profiles, student counts, and ratings.
- **Statistics Section:** Highlights platform statistics.
- **Footer:** Company links, resources, and legal information.
- **Responsive Design:** Adapts to different screen sizes using CSS media queries, Flexbox, and CSS Grid.

## 🛠️ Technologies Used

- **HTML5:** Structures the website content.
- **CSS3:** Handles styling, layouts, transitions, and responsive design.
- **JavaScript:** Adds interactive navigation and search-box toggling.
- **Font Awesome:** Provides icons throughout the website.
- **Google Fonts (Cairo):** Provides the website typography.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).
- The Live Server extension for Visual Studio Code (optional).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Muhaned-7/EverLearn.git
   ```

2. Navigate to the project directory:

   ```bash
   cd EverLearn
   ```

3. Open the project folder in Visual Studio Code.
4. Open `index.html` in your browser, or right-click the file and select **Open with Live Server**.
